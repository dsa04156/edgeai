# 센서 측정값으로 VD BATCH 실행하기

센서 디바이스를 원본으로 연결한 VD에서 측정 항목과 허용 수신 경과 시간을 선택합니다.
실행 요청을 만들 때 서버가 해당 항목의 최신값을 한 번 읽어 고정합니다.

1. **가상 장치**에서 센서용 템플릿과 호환 센서를 선택합니다.
2. 원본 슬롯의 **BATCH 측정 항목**을 선택하고 최대 수신 경과 시간을 저장합니다.
   기본30초이며1–300초까지 지정합니다. 기존 선택이 비어 있으면 실행 전에 수정하세요.
3. VD 실행을 시작하고 Ready를 확인합니다. 같은 SERVICE 버전으로 DAG를 발행합니다.
4. 실행 위치를 **가상 장치**로 지정하고 VD를 선택해 실행 요청을 저장합니다.
5. **실행 · 작업 · 결과**에서 Task를 선택합니다. **실행에 사용한 센서 입력**에서
   실제 사용한 값·단위·수신 시각을 보고, 원본 신원 details에서 센서 UID·모델·binding·VD revision을 확인합니다.
   실행이 완료되면 같은 상세의 **검증된 결과**에 출력 크기·형식·체크섬·파일 버전이 표시됩니다.

ONLINE이 아니거나 항목이 미수집·오래됨·잘못된 값이면 Run을 생성하지 않고 이유를 표시합니다.
같은 실행 요청 키를 재전송하거나 작업을 재시도하면 최초 입력을 유지합니다.
새 센서값으로 다시 실행하려면 새 실행 요청 키를 발급합니다.

SERVICE는 `EDGEAI_PARAMETERS_FILE`의 `vdInputs.sources.<슬롯>.properties.<항목>`에서
`value`, `dataType`, `unit`, `observedAt`을 읽습니다. `vdInputs`는 서버 예약 필드이므로
사용자가 Run/Task 매개변수로 지정할 수 없습니다. 센서와 원본 연결을 나중에 교체해도
기존 Task의 입력은 바뀌지 않습니다. 여러 VD를 지정한 DAG도 각 Task의 최초 VD 입력을 따로 유지합니다.

현재 범위는 BATCH 실행 시점의 측정값입니다. 연속 MQTT 소비는 후속 개발입니다.
Sense HAT 예제는 `runner/examples/temperature.py`이며 `temp_humidity` 섭씨 값을 화씨로 변환합니다.
운영용 SERVICE 이미지에는 예제 경로를 포함하고 실제 이미지 digest와 실행 경로를 지정해야 합니다.

검증 명령과 실제/fixture 경계는 [시험 명령](../testing/commands.md),
입력 보존과 거절 정책은 [ADR0117](../adr/0117-vd-sensor-batch-inputs.md)을 참고하세요.
