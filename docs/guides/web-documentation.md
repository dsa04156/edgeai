# 웹 문서 사용과 갱신

Dashboard의 **프로젝트 문서** 메뉴 또는 `/docs`에서 문서를 읽습니다.
기본 로컬 주소는 `http://127.0.0.1:13080/docs`입니다.

## 찾고 읽기

홈의 빠른 시작과 분야별 목록은 소개·실습·개념·사용·운영·참고·기여 순서로 구성합니다.
제목·경로·본문을 함께 검색하며 여러 단어를 입력하면 모두 포함하는 문서를 찾습니다.
**심화 자료·개발 기록 포함**을 선택하면 상세 구현·운영 절차와 ADR·검증·과거 기록도 검색합니다.
해당 기록 분야를 직접 선택해도 찾을 수 있습니다.

본문 옆 목록과 목차, 이전·다음 문서 링크로 이동합니다. 모바일에서는 목록과 목차를 펼쳐 사용합니다.
Markdown 표·코드·체크리스트·Mermaid를 표시하고 상대 문서 링크를 웹 주소로 변환합니다.
원시 HTML은 실행하지 않으며 이미지 링크는 대체 텍스트로 표시합니다.

## 원본과 목록 관리

`docs/`의 `.md`, `.yaml`, `.yml`과 명시된 README·PLAN·PROGRESS를 자동으로 읽습니다.
숨김 파일, `AGENTS.md`, symlink와 2 MiB 초과 파일은 제외합니다.
주요 안내의 분야·순서·설명은 `dashboard/docs-navigation.json`에 등록합니다.
등록하지 않은 새 문서도 **전체 문서와 개발 기록**에서 찾을 수 있습니다.

첫 `# 제목`을 목록 제목으로 사용합니다. 파일 추가 후 [문서 작성 기준](../contributing/documentation.md)에 따라
링크와 내용·적용 범위를 검증합니다. 임의의 저장소 소스 파일을 다운로드하는 기능은 제공하지 않습니다.

## 반영 방법

개발 서버에서는 문서를 수정한 뒤 새로고침하면 읽습니다.
production standalone과 Docker 이미지에는 빌드 시점의 문서를 포함하므로 갱신 후 다시 빌드·배포합니다.
웹 편집 기능은 없으며 저장소 파일이 단일 원본입니다.

## 화면 출처

사용자가 지정한 `http://docs.192.168.0.56.sslip.io/`의 밝은 배경·카드·문서 목록/본문/목차를 참고합니다.
홈의 개념 그림은 해당 사이트의 `assets/images/플랫폼-개념-비주얼-v2.png`를 로컬 자산으로 사용합니다.
그림은 실제 연결 장비 수나 운영 상태를 나타내지 않습니다.
