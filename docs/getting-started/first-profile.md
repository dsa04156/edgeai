# 첫 프로필 등록

프로필을 발행하고 같은 규격을 조회한 뒤 정리하는 짧은 실습입니다.
장비·클러스터를 변경하거나 센서 명령을 보내지 않습니다. 프로필 등록은 실제 DB에 저장됩니다.

## 시작하기 전에

[로컬 빠른 시작](../guides/local-development.md)을 완료하고 Dashboard에서 서버 연결을 확인합니다.
다른 사람이 사용하는 규격과 충돌하지 않도록 실습용 키를 선택합니다.

## 1. 장치 프로필 발행

1. **프로필 관리**에서 **장치 / DEVICE**를 선택합니다.
2. **새 버전 등록**을 누릅니다.
3. 키에 `tutorial-temperature`, 버전에 `1.0.0`을 입력합니다. 이미 사용 중이면 다른 키를 사용합니다.
4. JSON 규격에 다음 예시를 입력하고 **버전 발행**을 누릅니다.

```json
{
  "protocol": "mqtt",
  "description": "프로필 등록 흐름을 확인하는 실습용 규격"
}
```

이 예시는 프로필 저장을 익히기 위한 규격입니다. MQTT 장치나 연결을 자동으로 만들지 않습니다.

## 2. 결과 확인

목록에서 키·버전과 digest를 확인하고 해당 버전을 엽니다.
저장된 JSON이 입력과 일치해야 합니다. 같은 키·버전·내용을 다시 발행하면 기존 버전을 반환하고,
같은 버전의 내용을 바꾸면 충돌로 거절합니다.

## 3. 새 버전 만들기

상세의 **이 규격으로 새 버전 작성**을 누르고 버전을 `1.0.1`로 바꿉니다.
설명을 수정한 뒤 발행하면 두 버전이 독립적으로 남습니다. 기존 버전은 수정되지 않습니다.

## 4. 실습 정리

다른 장치나 실행에서 참조하지 않았다면 목록의 **삭제**와 **삭제 확인**으로 각 버전을 지울 수 있습니다.
사용 중이라는 응답이 나오면 연결한 대상을 먼저 확인합니다. DB에서 참조를 강제로 지우지 않습니다.
