# ADR0113 — STREAM 최초 경로 조회의 일시 실패 재시도

## 문제와 결정

Session은 실행 중 heartbeat의 일시 실패를 재시도했지만, 최초 경로 조회의 같은
`AssignmentUnavailable`은 즉시 실패로 처리했다. 실제 VD 통합 시험에서 최초 HTTP
조회 실패가 전체 연결 그룹의 실행 실패로 이어졌고, HTTPS 503 응답으로 재현했다.

journal·MQTT 연결·계산 프로세스를 만들기 전에 같은 경로 조회를 재시도한다.
대기 간격은 50ms부터 지수 증가하며 최대 1초다. 각 요청과 대기는 Session의 원래
기한 및 이미 읽은 모든 경로의 보수적인 유효시간으로 제한한다. 조회는 서버 lease를
갱신하지 않는다. 취소·만료·신원 거절·잘못된 응답은 재시도하지 않는다.

외부 checkpoint 복원, 데이터 처리, 완료 허가와 Result 확정의 조건은 기존 계약을
따른다. DB의 디스크 기록 지연이나 전체 회귀의 다른 실패까지 해결했다는 결정은 아니다.

## 검증 범위

실제 HTTPS에서 두 번의 503 뒤 정상 조회, 지속적인 503과 원래 기한 만료,
먼저 읽은 경로의 만료, 재조회 전 취소, 503 뒤 409 거절을 시험한다.
실패 경계에서는 journal과 모델을 시작하면 안 된다. native 이미지 발행은 양쪽
아키텍처에서 Runner 111개와 새 사례를 포함한 MQTT 107개 통과를 요구한다.
