# VD 센서값을 BATCH 작업 입력으로 고정

2026-10-08. 사용자가 별도 브랜치에서 설계·개발·검증을 요청했다. VD 원본 연결에 측정 항목과
최대 허용 수신 경과 시간을 저장하고, BATCH Run을 처음 생성할 때 해당 VD 작업의 센서값을 읽어 고정한다.
항목별 수신 시각·ONLINE 상태·고정 UID/DeviceModel을 검사하며, 센서 재등록이나 값의 변경이
같은 요청의 재호출·재시도 입력을 바꾸지 않게 한다. 기본 허용 시간은 30초, 설정 범위는 1–300초다.

고정 입력은 사용자 Run 매개변수와 분리한 불변 Task 입력으로 저장한다. 작업별 VD 선택이 달라도
다른 작업의 값을 덮어쓰지 않는다. 기존 Runner 매개변수 계약의 예약 필드 `vdInputs`로 전달하고,
Task 상세에서 실제 사용한 값과 출처를 조회한다. 오래된 수신 값이나 미래 시각, 미수집·UID 변경은
실행 생성 전에 거절한다. 원본 교체와 재시도는 이미 고정된 입력을 유지한다.

기존 UUID Device·STREAM 이력과 원본 없는 emulation은 유지한다. 새 센서 VD의 측정 항목이
미설정이면 BATCH 실행 시 설정 안내로 거절한다. 연속 MQTT 소비와 Runner/STREAM 고도화는 후속 범위다.

검증 경계는 기존 공개 VD/Workflow Run/Task/Result API, 실제 격리 PostgreSQL,
Runner HTTP 할당 계약 및 실제 처리 프로그램, PC·모바일 웹이다. 센서 외부 경계의 실패·재생성은
명시적 fixture로 검증하고, Sense HAT 최신값을 읽는 실제 경로는 별도 수용 시험에서 확인한다.
