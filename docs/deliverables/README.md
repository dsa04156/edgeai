## 검증 결과의 구분

코드와 시험 소스를 확인한 내용, 과거 수행 기록을 인용한 내용, 이번 개정에서 다시 실행한 시험을 구분했다. 새 환경에서 따라야 할 인수 절차는 수행 전 통과로 표시하지 않는다. 예시 주소·UUID·JSON은 본문 형식을 설명하며 실제 장비의 관측 결과가 아니다.

| 2026-10-20 개정 시 재실행 | 결과 | 검증 범위 |
|---|---|---|
| 원본 collector·연속 규칙 compiler | 5개 통과 | 중복·저장 재시도·항목 잠금·규칙 생성·자료형 |
| DAG·typed 입력·전환 정책 | 8개 통과 | 그래프·큰 정수·선택 형식·임계값 정책 |
| Runner | 11개 통과 | 실제 자식 프로세스와 로컬 HTTP fixture의 실행·파일·취소 |
| native API 경계 | 27개 통과 | 세션·CSRF·멱등 키·정확한 숫자·메트릭 표시 데이터 |

위 51개는 단위·fixture 시험이다. 실제 장비, Kubernetes 전환, InfluxDB 장애·복구, 24시간 운전을 이번 개정에서 새로 검증한 결과가 아니다. 3분 3,055건 대조, 실제 NODE 결과 24, 센서·VD 연계 종료 등은 과거 기록을 인용했으며 당시 원시 로그를 이번에 다시 집계하지 않았다.

공개 ETRI 사례의 문서 체계와 기술 본문을 참고해 내용을 보강했다. 현행 기관의 필수 서식·의무 분량을 확인한 것은 아니므로 등록 시 실제 제출처의 행정 항목과 검토 기준을 적용한다.
