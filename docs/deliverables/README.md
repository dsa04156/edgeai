# 기술자료 등록 문서

TM은 설계와 구현 및 검증을 설명하며 TDP는 관련 소스 구성, 인터페이스, 설치와 운영 및 인수 시험을 설명한다.
TDP-01은 TM-01부터 TM-03까지, TDP-02는 TM-04부터 TM-06까지 연결한다.
등록번호, 과제명, 작성 부서와 담당자 기입란을 제공하며 임의 행정 정보는 부여하지 않는다.

기준일은 2026년 10월 20일이고 기술 기준 소스는 `1170c1e88667ea22bba2b21844456c18821e0213`이다.
현재 저장소의 안내 문서는 이후 변경될 수 있으므로 Word의 기술 참고 링크는 기준 커밋에 고정한다.
각 문서의 Markdown은 수정 가능한 원본이며 편집 가능한 Word 8개와 함께 제공한다.
Word 산출물과 묶음 파일은 Git에서 제외된 `output/technical-documents/`에 보관한다.
소스 본체는 기준 저장소를 사용하며 문서 묶음에 실행 바이너리, 이미지, 실제 자격 증명과 운영 데이터는 포함하지 않는다.

시험 결과는 [현재 상태](../../PROGRESS.md), 잔여 범위는 [개발 단계](../../PLAN.md)와 대조한다.
