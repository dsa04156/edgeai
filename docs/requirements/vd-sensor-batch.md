# VD 센서 BATCH 수용 기준

작업 브랜치: `feat/vd-sensor-batch`. 기준 커밋: `4853a39`(작업 시작 시 관리 구현 보존).

1. VD 등록·수정에서 원본 센서별 측정 항목과 최대 허용 수신 경과 시간을 선택·조회한다.
2. 센서 UID·모델·선택 항목의 존재를 검사한다. 선택 변경은 기존 binding을 닫고 새 이력을 만든다.
3. BATCH Run 생성 시 작업별 VD 원본을 자동으로 해석한다. 값·수신 시각·센서 신원·binding·VD revision을 고정한다.
4. ONLINE이 아니거나 미수집·오래됨·허용 범위를 벗어난 미래 시각·잘못된 값·신원 변경이면 Run을 만들지 않는다.
5. 같은 Idempotency-Key 재호출과 작업 재시도에서 센서를 다시 읽지 않고 최초 입력을 유지한다.
6. 여러 VD의 작업 입력이 섞이지 않으며, Run/Task 매개변수로 예약 입력 `vdInputs`를 위조할 수 없다.
7. 기존 Runner로 실제 처리 프로그램을 실행하고 검증된 Result를 조회한다. Task 상세에서 사용한 센서값과 원본을 보여준다.
8. PC·모바일에서 선택·저장·검증 오류·실행 상세·결과 이동을 확인한다.
9. 통합 시험은 개발 DB와 분리한다. 기존 인증 기대값 실패 5건을 현재 관리 API 계약에 맞게 정리한다.
10. 기존 관리 웹·센서 설정을 보존하고, 검증용 데이터·프로세스·자원을 정리한다.

최초 실제 수용은 Sense HAT의 온도 한 항목으로 수행한다. 실제 센서 읽기와 처리·Result 경로를
확인한 증거, 외부 실행 경계를 fixture로 대체한 증거는 구분해 기록한다.
