# 사용자 정의 VD 처리 요구사항

## 조합형 간편 등록 (2026-10-14)

M6 등록창은 통합 온도·온도 편차·3축 회전/가속도 제곱합·회전/가속도 XY/XZ/YZ 평면 제곱합10종을 이름으로 선택하고 필요한 센서를 명시적으로 고른다. 통합 온도는 두 값의 평균, 편차는 첫 온도에서 두 번째 온도를 뺀 값이며 벡터는 선택한 축의 제곱합이다. 조합값 그대로·최근 평균·최소·최대를 기존 연속 처리 API로 등록한다. 임계값·필터를 조합 프리셋에 추가하지 않으며 기존 단일 센서와 직접 계산식 설정은 유지한다.

입력은 catalog의 숫자 타입·온도/회전/가속도 측정 항목·축·동일 단위를 기준으로 선택하고 같은 센서를 중복 연결하지 않는다. 입력 누락·catalog 변경 후 호환 실패 시 간편 등록을 막으며 임의 센서로 바꾸지 않는다. 단위는 현재 catalog에서 구성하고 원시값은 물리 단위로 환산하지 않는다. 기본1초·창5개·전체 결과7일 보관, 생성 키와 실패 재시도·직접 설정 전환·모달 초안 유지 계약을 재사용한다. 기존 등록·원본 센서·계산/저장 엔진 계약은 변경하지 않는다.

## 연속 가상디바이스 모드 추가 (2026-10-13)

물리 센서 등록은 선택 가능한 입력을 추가하며 가상디바이스를 자동 생성하지 않는다. 사용자가 입력과 계산식을 등록할 때 가상디바이스 하나가 생긴다. 하나의 센서를 여러 가상디바이스에서 재사용할 수 있다. 하나의 가상디바이스 안에 평균·최댓값·경보를 등록하면 가상디바이스 1개, 독립 출력 행 3개가 된다. 각 계산을 따로 등록하면 가상디바이스 3개가 된다. 입력·출력은 각각 최대 16개이다.

물리 측정 항목의 Device·DeviceStatus와 웹 행은 계속 분리한다. 연속 계산 결과는 가상디바이스의 출력 행·상태·이력이며 별도 파생 CRD를 생성하지 않는다. 입력 프로토콜과 계산은 분리한다. MQTT·Modbus TCP·OPC UA·Serial JSON·Sense HAT·HTTP JSON을 기존 Mapper에서 수집하며, 새 센서는 메타데이터 목록에 자동 표시하되 기존 입력 바인딩은 사용자가 명시적으로 수정할 때만 변경한다.

새 CONTINUOUS_EKUIPER v3 모드는 SERVICE와 개별 VD Pod를 요구하지 않는다. 일반 AMD64 워커 CG004의 `ekuiper` 네임스페이스에 설치된 eKuiper 2.4.2와 agent를 공유한다. 출력별 소유 규칙을 생성하고 제한된 산술·비교·논리식, scalar·AVG·MIN·MAX·임계값·필터를 제공한다. 기존 VD BATCH·FFT·supervisor 경로는 ADR 0115에 따라 제거된 상태로 유지한다. 일반 SERVICE/Runner 실행은 보존하며 연속 VD 간 연결은 지원하지 않는다.

기본 1초의 정렬된 tick에서 모든 필수 입력의 UID·실제 적용 설정·원래 관측 시각·세션 순서를 확인한다. 입력 누락·만료·설정 변경·연결 재수립 시 세대와 창을 초기화한다. 유효한 연속 tick의 창은 1–1024개이며, 사용자가 임의 SQL·sink·plugin을 제출할 수 없다. Mapper의 물리 읽기와 DMI 보고 횟수는 늘리지 않는다.

결과 전체는 별도 PostgreSQL에 기본 7일(1–30일) 저장하며 그래프 집계는 조회에서만 수행한다. 이력 장애 때 최신 결과는 계속 제공하고 누락 구간을 표시한다. 복구 뒤 과거 입력·결과를 재생하거나 소급 저장하지 않는다. CG002의 초기 400Gi PVC는 실제 저장 경로의 여유 공간 480Gi 이상을 사전 확인해야 한다. 500개 측정 항목·200개 활성 VD·500개 규칙 및 보수적인 저장 예산을 적용한다.

운영 활성화 전 실제 17개 측정 항목, 각 프로토콜 simulator, 과거 VD 실행 차단과 일반 Runner 회귀, 규모·저장 부하, 실제 24시간 연속 수용 검증이 필요하다. 기준은 p95 결과 전달 2초 이하, 정상 입력 손실·중복 없음, 제한된 메모리·큐이다. 확인하지 않은 결과를 통과로 기록하지 않는다. 기능 기본값은 비활성이다. 새 공개 등록은 continuous 전용이다. profiles/VD 발행과 기존 일반 VD 등록 API는 제공하지 않는다.
